## The gate (strategy §2.3)

Deterministic, pure `(facts, config) → { tier, checks }`. Tiers are **structural
configuration bars, not quality ratings**:

- **listable (Tier-L):** known-safe template · no mint/tax/blacklist/upgrade ·
  LP locked ≥ 30d · team allocation on-chain-vested.
- **flagship (Tier-F):** Tier-L **plus** admin renounced or timelock-only ·
  LP locked ≥ 365d · no pause power · insider float ≤ 20%.
- **none:** meets neither — **not labelled "unsafe."** Disclosures are still
  published; buyers judge for themselves.

Floors are config (`defaultGateConfig`), so the launch gate policy is tunable
without code changes.

## Why this is the differentiator

Every other launcher hands buyers a token address and a vibe. Tegridy publishes
a machine-checked, revocable, EAS-attestable disclosure of exactly what powers
the contract grants and whether liquidity/insiders are locked — generated by
code, no human vouching (which is both a liability and a bus-factor per the
red-team). It composes: bots, screeners, and terminals can consume the Fact
Sheet as a safety primitive.
