# BOTH served origins are declared. RFC 9116 §3 says a Canonical URI that does not
# match where the file was actually fetched from is grounds to distrust the whole
# file, and this listed only memetic.fun while the app's own SITE_URL
# (frontend/src/lib/constants.ts) is memetics.finance — so a strict parser fetching
# the canonical origin could reject the policy it came from.

Canonical: https://memetic.fun/.well-known/security.txt
