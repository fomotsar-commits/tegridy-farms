# RFC 9116 §3: a Canonical URI that does not match where the file was actually
# fetched from is grounds to distrust the whole file. This once listed only
# memetic.fun while the app's own SITE_URL (frontend/src/lib/constants.ts) was
# memetics.finance, so both were declared to stop a strict parser fetching the
# canonical origin from rejecting the policy it came from.
#
# 2026-09-09: back to ONE, because memetic.fun now 301s to the canonical host
# (frontend/vercel.json). A Canonical URI must be a place this file is SERVED, and
# a redirect is not — the second line had become the very mismatch it was added to
# prevent. A researcher who starts at memetic.fun still lands here, via the 301.
